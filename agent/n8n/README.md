# Сценарии n8n

В главе 1.3 создаётся сценарий «Агент-сторож: запуск».

После настройки и публикации сценария экспортируйте его из интерфейса n8n (меню сценария → Download) и сохраните сюда под именем:

`agent-started.json`

Экспорт делается после настройки узлов Webhook → Basic LLM Chain (с подключённым Ollama Chat Model) → Send an Email. Учётные данные Ollama и SMTP настраиваются в n8n отдельно; секреты и пароли в Git не добавляются.

Для проверки локально используется тестовый адрес:

`http://localhost:5678/webhook-test/agent`

После публикации используется боевой адрес:

`http://localhost:5678/webhook/agent`
