# ЛР 7. Потоки Python и GIL

Система: Windows 10, Intel Core i5-12400F  
Ядер (логических процессоров): 6 (12)  
Версии Python (обычный и без GIL): Python 3.14.0 и Python 3.14.10 free-threaded

## Python с GIL

Процент процесса и число потоков: общая загрузка ЦП во время эксперимента — 21%; у процесса Python отображалось 8 потоков.  
Сколько потоков выполняется одновременно: один поток выполняет Python-код в каждый момент времени из-за GIL.

## Python без GIL

Процент процесса и проценты потоков: общая загрузка ЦП во время эксперимента — 59%; наблюдалась нагрузка на несколько логических процессоров одновременно. GIL отключён (`sys._is_gil_enabled() == False`).

## Время работы

С GIL, 1 / 2 / 4 потока: 3.18 / 3.18 / 3.16 с.  
Без GIL, 1 / 2 / 4 потока: 3.57 / 1.93 / 1.08 с.  
Без GIL с PYTHON_GIL=1: 3.55 / 3.54 / 3.50 с.  
Ожидание, 1 и 4 потока: 2.00 / 2.00 с.

Почему ожидающие потоки ускоряются и с GIL: во время `sleep()` поток освобождает GIL, позволяя другим потокам работать или ожидать одновременно. Поэтому четыре потока с ожиданием по 2 секунды завершаются примерно за 2 секунды, а не за 8.

Не получилось: точные проценты загрузки отдельных потоков не измерены; зафиксирована общая загрузка процессора.
