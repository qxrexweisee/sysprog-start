# ЛР 2. Программа в отладчике

**Система:** Windows · **отладчик:** Visual Studio Debugger (MSVC, cppvsdbg)

## Остановка и переменные

Программа без отладчика напечатала: `agent: total=6 area=12`

Точка останова на строке **20** (`strcpy(name, "agent")`).

До выполнения `strcpy`: p.x = **3**, p.y = **4**, total = **0**.

После выполнения `strcpy`: p.x = **3**, p.y = **4**.

Строку 16 отладчик пропустил, потому что инициализация структуры была выполнена до первой остановки на точке останова.

name[0] = **97 (код буквы a)**, завершающий ноль в ячейке **name[5]**.

## Цикл и функция

На кадре цикла: i = **2**, total = **1**; после следующего шага total = **3**.

В стеке внутри area **2 строки**, сверху функция **area()**, ниже `main()`.

Команда умножения в машинном коде: `imul eax, dword ptr [rsp+24h]`.

Перед printf: a = **12**, total = **6**.

Код завершения программы: **0**.

Не получилось: **существенных проблем при настройке и запуске отладчика не возникло.**
